# Sistema de Gestión Académica (SGA)

## Descripción

Proyecto desarrollado para la asignatura Arquitectura de Software de la Escuela Tecnológica Instituto Técnico Central (ETITC).

El Sistema de Gestión Académica (SGA) permite la administración de estudiantes, docentes, programas académicos, asignaturas, grupos, matrículas, calificaciones, reportes institucionales y auditoría.

## Características Principales

- Gestión de Usuarios
- Gestión de Programas Académicos
- Gestión de Asignaturas
- Gestión de Grupos
- Matrículas en Línea
- Gestión de Calificaciones
- Reportes Académicos
- Auditoría y Trazabilidad
- Seguridad basada en JWT
- Control de Acceso por Roles (RBAC)

## Roles del Sistema

### Administrador

- Gestión completa del sistema.

### Coordinador Académico

- Gestión curricular y asignaciones.

### Docente

- Registro y consulta de calificaciones.

### Estudiante

- Matrícula y consulta académica.
